# @matinee/sdk

The reference TypeScript client for the [Matinee AI](https://matinee.ai) v1
API, together with the OpenAPI specification it is generated from.

**Status, stated plainly:** this is pre-release. The v1 API is fully
specified — 208 operations, a registry of 84 error codes, one envelope, one
pagination convention — but **no hosted server serves it yet**. The client
in this repository is written against the specification, typechecks against
types generated from it, and is exercised by a test suite over a mock
transport. It is not published to npm, and nothing here can reach a
production API, because there is none. When that changes, this README will
say so.

## What is here

```
src/   The client: typed request core, retries, idempotency, cursor
       pagination, webhook signature verification, typed errors.
api/   The specification artifacts, vendored from the platform's typed
       contract: openapi.json (OpenAPI 3.1), matinee.d.ts (generated by
       openapi-typescript), postman-collection.json.
test/  26 unit tests over a scripted fetch — headers, envelope, error
       mapping, retry policy, pagination, signatures.
```

Zero runtime dependencies. The only dev dependency is TypeScript.

## Design, in five sentences

Every path, method, parameter and error code the client knows comes from
`api/matinee.d.ts`, so it cannot describe an endpoint the specification does
not define. Every response is the `{ data, meta }` envelope, and every error
is a typed object carrying the full 84-code union plus the `request_id` that
connects it to a server-side log line. Retries happen only where retrying is
correct: rate limits and server errors — and writes only when an
`Idempotency-Key` makes the retry safe. Collections are consumed through a
cursor-driven async iterator, because the API has no offset pagination to
misuse. Webhook signatures are verified in constant time.

## Use

```ts
import { MatineeClient } from '@matinee/sdk'

const matinee = new MatineeClient({
  apiKey: process.env.MATINEE_API_KEY!,
  organizationId: process.env.MATINEE_ORG_ID!,
  environment: 'sandbox',
})

const { data: customer } = await matinee.post('/customers', {
  body: { external_id: 'user-0001' },
  idempotencyKey: 'customer-user-0001',
})

for await (const execution of matinee.paginate('/reward-executions', {
  query: { limit: 25 },
})) {
  // cursor pagination, handled
}
```

A mistyped path or method is a compile error, not a 404 at runtime.

## Develop

```sh
npm ci          # installs TypeScript, nothing else
npm run check   # typecheck (strict)
npm test        # node:test over a scripted fetch — no network
```

Node 22.18+ (the tests run TypeScript natively via type stripping).

## Provenance

This code was developed inside the Matinee AI platform repository and is
extracted here as the publishable surface. The artifacts in `api/` are
generated from the platform's typed API contract and re-vendored on change —
they are outputs here, not sources. The package carries `"private": true`
until a first version is deliberately published to npm.
